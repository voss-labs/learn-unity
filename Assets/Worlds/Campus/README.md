# Campus

Level 1 of the main building at Vidyalankar Institute of Technology, Mumbai: blocks A to G around the main hall, two canteens, and three working staircases. Press 1 to 8 to jump between viewpoints.

This is a draft built by hand from photos and a satellite view, not a measured map. Sizes and positions are estimates.

## How it was built

The campus is not modelled in Unity. It is generated by code in [vmaps](https://github.com/voss-labs/vmaps), the TypeScript and Three.js campus walkthrough. One command exports it to `campus.glb`, which holds four groups:

| Group | What it holds |
| --- | --- |
| Visual | The meshes you see |
| Solids | One empty object per obstacle. Its position and scale describe the box |
| Floors | One empty object per walkable floor, with stairs as tilted boxes |
| Places | The viewpoints, each with a `Look` child showing where to face |

`CampusWorld.cs` turns Solids and Floors into colliders when the world starts, and gives the Places to the Walker. Lesson 3 walks through it.

Carrying collision data inside the model file means there is only one source of truth. Change the campus in vmaps and re-export, and everything updates together.

## Change the campus

Change it in vmaps, not here. From a vmaps checkout next to this repo:

```bash
npm run export:unity -- ../learn-unity/Assets/Worlds/Campus
```

## What to try

- Stand at the top of the stairs by the main gate (press 1). Walk down into the opening, then come back up.
- Climb the stair tower beside G to the top landing and look across the hall. Press 3, and it is across the hall from you.
- Walk the C and F stairwell. It turns at a half-landing, so there are two ramps and a flat floor between them.
